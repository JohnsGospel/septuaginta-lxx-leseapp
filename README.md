# Septuaginta Deutsch – private Testfassungen

Dieses Paket ist nach Plattformen geordnet. Die Installationsschritte stehen in [INSTALLATION.md](INSTALLATION.md).

- `Android/`: signierte Offline-APK.
- `Web/`: Offline-Browserfassung für Windows; `START.html` liegt in der ZIP.
- `Apple/`: iPhone-Web-App und Xcode-Quellprojekt. Noch keine direkt installierbare iPhone-IPA.

Alle einzelnen Dateien liegen unter 25 MiB und können über die GitHub-Oberfläche in ein **privates** Repository geladen werden. Die Veröffentlichungs- und Weitergaberechte am aus einer PDF übernommenen deutschen Text sind nicht bestätigt. Deshalb keine öffentliche Bereitstellung der Dateien oder des Textbestands.
